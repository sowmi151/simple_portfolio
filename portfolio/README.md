# Personal Portfolio: Sowmiya A

Static portfolio built with HTML5 and CSS3. No JavaScript needed.

## Structure
```
portfolio/
├── index.html
├── css/style.css
├── assets/avatar.svg
└── README.md
```

## Before you publish (edit index.html)
1. Replace `your.email@example.com` (2 places) with your real email.
2. Replace `your-repo-name` in the 3 project links with your real repositories.
3. Update the project titles and descriptions.
4. Swap `assets/avatar.svg` for your photo (e.g. `assets/photo.jpg`) and update the `src` of `.hero__photo`.

## Hosting
Push to GitHub, then Settings > Pages > Deploy from branch `main` (root).
