💻 How to Run Locally

If you want to run this project on your local machine:

Clone the repository:

git clone https://github.com/sowmi151/simple_portfolio.git


Navigate to the folder:

cd simple_portfolio


Open the project:
Open the index.html file in any modern web browser, or use VS Code's "Live Server" extension for a better development experience.
